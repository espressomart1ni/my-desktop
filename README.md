# Riddhima Kapoor | Portfolio

Two self-contained pages (all pictures are embedded, so each works from any folder):

- `index.html`   the new macOS-desktop portfolio (scroll snaps slide by slide, dock navigation). This is the one GitHub Pages shows.
- `classic.html` the previous scrolling version, kept as a backup.

## Open locally
Double-click `index.html`.

## Deploy on GitHub Pages
1. Create a new public repository (e.g. `portfolio`).
2. Upload `index.html` (and optionally `classic.html` and `.nojekyll`) to the repository root.
3. Settings > Pages > Build and deployment: Source = "Deploy from a branch", Branch = `main`, folder = `/ (root)`, then Save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` after about a minute.
   (Name the repo `<your-username>.github.io` for the shorter `https://<your-username>.github.io/`.)

The `images/` folder is only a backup of the cropped pictures; the pages do not use it.
